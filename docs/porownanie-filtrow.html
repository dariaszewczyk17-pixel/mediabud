8 PRAKTYK
1

Dynamiczne liczniki produktów

Każda wartość filtra pokazuje liczbę dostępnych wyników w nawiasie. Zapobiega "dead-end" selections — 73% użytkowników porzuca przy 0 wynikach.

✓ WDROŻONE
2

Active Filter Chips (pills)

Aktywne filtry widoczne nad siatką produktów z przyciskiem X do usunięcia. 80% użytkowników zapomina które filtry zastosowało.

✓ WDROŻONE
3

Przycisk "Wyczyść wszystkie"

Jeden klik resetuje cały stan filtrów. Kluczowy dla recovery z zero-results. Baymard: strony bez tego tracą 35-40% sesji.

✓ WDROŻONE
4

URL-based filter state

Filtry zakodowane w URL (?brand=Weber&price=20-250) wspierają back button, deep linking, bookmarki i SEO facetów.

✓ WDROŻONE (useSearchParams)
5

Mobile Filter Drawer

Full-screen panel filtrów na mobile z animacją slide. Standard mobile e-commerce — 78% stron które tego nie mają traci konwersje mobilne.

✓ WDROŻONE (FilterBarFuturistic)
6

Histogram cen nad sliderem

Rozkład produktów w pasmach cenowych wyświetlany nad range sliderem. Wg BTNG.studio zwiększa engagement o 20-30%. Żaden z 4 sklepów nie posiada.

⚡ DO WDROŻENIA
7

Progressive Disclosure

Facety z >8 wartościami powinny pokazywać "Pokaż wszystkie X opcji". Zmniejsza cognitive load i czas skanowania listy.

⚡ CZĘŚCIOWO (brak "Pokaż więcej")
8

Zero-Results Recovery Page

Strona bez wyników musi sugerować usunięcie pojedynczych filtrów, pokazywać bestsellery i search bar. Dobra strona 0-wyników retains 35-45% sesji.

REKOMENDACJE

PRIORYTETOWE
P1

Dodać sortowanie: "Najwyżej oceniane" + "Nowości"

Wszystkie 3 konkurencyjne sklepy oferują te opcje. Castorama ma 5 opcji, Media Bud tylko 4 bez kluczowych pozycji. Oceny to drugi najczęściej używany filtr po cenie — wg Baymard Institute jest oczekiwany przez 68% kupujących B2C.

SORTOWANIE BTNG.studio ↑ WYSOKI WPŁYW NA KONWERSJĘ
P1

Histogram cen nad range sliderem

Wykres słupkowy pokazujący rozkład produktów w przedziałach cenowych wyświetlany bezpośrednio nad sliderem. BTNG.studio: +20-30% engagement z filtrem ceny. Żaden z 4 analizowanych sklepów nie posiada — to realna przewaga dla Media Bud.

FILTR CENY BTNG.studio ↑ SZANSA NA WYRÓŻNIENIE
P1

Ulepszyć stronę zero-results

Gdy filtr daje 0 wyników — pokazać: (1) które filtry usunąć, (2) bestsellery kategorii, (3) search bar z sugestiami. Dobra strona zero-results zatrzymuje 35-45% sesji wg Baymard. Aktualny empty state jest zbyt pasywny.

EMPTY STATE BAYMARD ↑ RETENCJA SESJI +40%
P2

Filtry specyficzne dla kategorii budowlanych

Leroy Merlin i Castorama posiadają filtry dostosowane do kategorii: izolacje → lambda, grubość; płytki → format, R-class; farby → wydajność m²/l, rodzaj podłoża. To kluczowa różnica dla B2B/profesjonalistów. Media Bud ma unikalne pozycjonowanie B2B w Lublinie — warto to wzmocnić.

FILTRY B2B → DIFFERENTIATOR B2B
P2

Progressive disclosure — "Pokaż wszystkie X opcji"

Listy filtrów z >8 wartościami powinny być inicjalnie zwinięte i rozwijane przyciskiem "Pokaż wszystkie 23 marki". Zmniejsza cognitive load, poprawia czytelność na mobile. OBI i Leroy Merlin stosują ten wzorzec.

UX PATTERN MOBILE → LEPSZA CZYTELNOŚĆ
P2

Oceny produktów + sortowanie po ocenach

OBI, Castorama i Leroy Merlin pokazują gwiazdki i liczbę opinii na kartach produktów. Dla Media Bud z produktami Sanity — można agregować opinie z zewnętrznych źródeł lub budować prosty system własny. Oceny budują zaufanie i są czwartym najczęściej używanym filtrem.

SOCIAL PROOF SORTOWANIE → TRUST SIGNAL
P3

Sticky "Pokaż X wyników" w mobile drawerze

Wewnątrz mobilnego panelu filtrów sticky przycisk zawsze widoczny na dole pokazuje aktualną liczbę wyników: "Pokaż 47 wyników". BTNG.studio: eliminuje niepewność użytkownika czy filtry dają sensowny wynik.

MOBILE UX BTNG.studio ↗ MOBILE POLISH
P3

Visual swatches dla kolorów farb i tynków

Dla kategorii farby i tynki — zamiast tekstu "Biały / Szary / Beżowy" pokazać wizualne próbniki kolorów (kółka z kolorem). Leroy Merlin stosuje to dla farb. Wysoki impact dla sektora dekoracyjnego i klientów B2C.
